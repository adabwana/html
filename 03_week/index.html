CSS Selectors

CSS selectors target HTML elements to apply styles. Understanding selectors is key to effective styling.

Basic Selectors

Element selector (p)

ID selector (#id-selector)

Class selector (.class-selector)

p { color: blue; }           /* Element */
#unique { font-size: 20px; }   /* ID */
.highlight { background: yellow; } /* Class */

Advanced Selectors

Parent element

Child element (descendant)

Adjacent sibling

General sibling

.parent .child { color: red; }    /* Descendant */
.parent > .child { font-weight: bold; } /* Direct child */
.adjacent + .sibling { color: green; } /* Adjacent sibling */
.adjacent ~ .sibling { color: blue; }  /* General sibling */

The Box Model

Every HTML element is a rectangular box. Understanding the box model is crucial for layout.

Box Model Components

Content
  • Content: The actual content (text, images, etc.)
  • Padding: Space between content and border
  • Border: Line around the padding
  • Margin: Space outside the border
.box {
    width: 200px;      /* Content width */
    padding: 20px;     /* Padding all sides */
    border: 2px solid black;  /* Border */
    margin: 10px;      /* Margin all sides */
}

Colors and Backgrounds

Named color: red
Hex: #3498db
RGB: rgb(255, 165, 0)
HSL: hsl(120, 100%, 50%)
color: red;                    /* Text color */
background-color: #f0f0f0;    /* Background color */

opacity: 0.8;                   /* Transparency */
