Media Queries

Media queries allow you to apply different styles based on device characteristics like screen size, resolution, and orientation.

Basic Media Query Syntax

/* Mobile first - default styles for small screens */
.container {
    width: 100%;
    padding: 10px;
}

/* Tablet and up */
@media (min-width: 768px) {
    .container {
        width: 750px;
        padding: 20px;
    }
}

/* Desktop and up */
@media (min-width: 992px) {
    .container {
        width: 970px;
        padding: 30px;
    }
}

Common Breakpoints:

  • Mobile: 320px - 767px
  • Tablet: 768px - 991px
  • Desktop: 992px - 1199px
  • Large Desktop: 1200px+

Media Query Features

Screen Size

/* Minimum width */
@media (min-width: 768px) { ... }

/* Maximum width */
@media (max-width: 767px) { ... }

/* Between two widths */
@media (min-width: 768px) and (max-width: 991px) { ... }

Device Orientation

/* Portrait orientation */
@media (orientation: portrait) { ... }

/* Landscape orientation */
@media (orientation: landscape) { ... }

Device Type

/* Print styles */
@media print { ... }

/* High resolution screens */
@media (-webkit-min-device-pixel-ratio: 2) { ... }

Flexbox Layout

Flexbox is a modern layout system that makes it easy to create flexible, responsive layouts.

Flexbox Container Properties

Item 1
Item 2
Item 3
.container {
    display: flex;              /* Enable flexbox */
    justify-content: center;    /* Horizontal alignment */
    align-items: center;        /* Vertical alignment */
    flex-direction: row;        /* Direction: row, column */
    flex-wrap: wrap;           /* Wrap items to new line */
}

Flexbox Item Properties

Small
Medium
Large
.item {
    flex-grow: 1;      /* How much item can grow */
    flex-shrink: 1;    /* How much item can shrink */
    flex-basis: auto;  /* Initial size */
    /* Shorthand: flex: 1 1 auto; */
}

Practice Exercises

Exercise 1: Mobile-First Navigation

Create a navigation menu that:

  • Stacks vertically on mobile (320px and below)
  • Displays horizontally on tablets (768px and up)
  • Centers items on desktop (992px and up)
  • Uses a hamburger menu on very small screens

Exercise 2: Responsive Grid Layout

Build a responsive grid that:

  • Shows 1 column on mobile
  • Shows 2 columns on tablets
  • Shows 3 columns on desktop
  • Uses Flexbox or CSS Grid
  • Has consistent spacing between items

Exercise 3: Responsive Images

Make images responsive by:

  • Setting max-width: 100% and height: auto
  • Using different image sizes for different screen sizes
  • Implementing art direction with element
  • Testing on various device sizes

Exercise 4: Print Styles

Create print-friendly styles:

  • Hide navigation and footer for printing
  • Use a serif font for better readability
  • Remove background colors and images
  • Ensure links show their URLs
