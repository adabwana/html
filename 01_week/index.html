HTML Document Structure

Every HTML page starts with a basic structure. Here's what you need to know:

The Basic HTML Template

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <!-- Your content goes here -->
</body>
</html>

Key Components:

  • <!DOCTYPE html> - Tells the browser this is an HTML5 document
  • <html> - The root element of the page
  • <head> - Contains metadata about the page
  • <body> - Contains the visible content

Paragraphs and Text

The paragraph tag creates blocks of text. You can format text within paragraphs:

This is a regular paragraph with bold text and italic text.

You can create highlighted text and show deleted text.

For code snippets, use <code> tags.

<p>This is a <strong>bold</strong> word.</p>
<p>This is <em>italic</em> text.</p>
