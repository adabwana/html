HTML Forms

Forms allow users to input data and interact with your website. They're essential for user interaction.

Form Structure

Every form needs opening and closing <form> tags with attributes:

<form action="submit.php" method="post">
    <!-- Form elements go here -->
</form>
  • action - Where to send form data
  • method - How to send data (GET or POST)

HTML Tables

Tables organize data in rows and columns, perfect for displaying structured information.

Basic Table Structure

Name Age City
John Doe 25 New York
Jane Smith 30 London
Bob Johnson 35 Paris 
<table>
    <thead>
        <tr>
            <th>Header 1</th>
            <th>Header 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Data 1</td>
            <td>Data 2</td>
        </tr>
    </tbody>
</table>

Table Elements

  • <table> - Container for the table
  • <thead> - Header section
  • <tbody> - Body section (main data)
  • <tfoot> - Footer section (optional)
  • <tr> - Table row
  • <th> - Header cell (bold, centered)
  • <td> - Data cell

Advanced Table Features

Spanning Cells

Student Grades Average
Math Science English
Alice 95 87 92 91.3

<th colspan="3">Grades</th>  <!-- Spans 3 columns -->
<td rowspan="2">Data</td>    <!-- Spans 2 rows -->

Practice Exercises

Exercise 1: Create a Contact Form

Build a contact form with the following fields:

  • Name (required text input)
  • Email (required email input)
  • Phone (optional tel input)
  • Subject (select dropdown)
  • Message (textarea)
  • Newsletter checkbox
  • Submit and Reset buttons

Exercise 2: Student Grade Table

Create a table showing student grades with:

  • Header row with student names and assignment columns
  • Multiple student rows with scores
  • A footer row showing averages
  • Use colspan for assignment categories

Exercise 3: Survey Form

Create a survey form that includes:

  • Radio buttons for single-choice questions
  • Checkboxes for multiple-choice questions
  • Rating scale using number inputs
  • Open-ended questions with textareas
